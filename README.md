# Google Frontpage Clone

A modern, responsive clone of the Google homepage built with HTML and CSS. This project recreates the iconic Google search interface with a beautiful gradient background and smooth animations.

## 🚀 Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI**: Beautiful gradient background with glass-morphism effects
- **Interactive Elements**: Hover animations and smooth transitions
- **Search Functionality**: Google-style search bar with icons
- **Shortcuts**: Quick access to GitHub and YouTube
- **Clean Code**: Well-organized HTML and CSS structure

## 🎨 Design Elements

- **Gradient Background**: Modern blue-purple gradient
- **Google Logo**: Centered with proper typography
- **Search Bar**: Rounded design with search and microphone icons
- **Shortcuts**: GitHub and YouTube quick access buttons
- **Footer**: Privacy, Terms, Settings links with customize Chrome option
- **Developer Credit**: Attribution to conadux

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling with flexbox, gradients, and animations
- **Google Material Icons**: For search and microphone icons
- **Responsive Design**: Mobile-first approach

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Konadu-Prince/google-frontpage.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd google-frontpage
   ```

3. **Open in your browser**:
   - Simply open `index.html` in any modern web browser
   - Or use a local server for development
